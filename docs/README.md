## Branch work notebooks

At branch finalisation, record the branch's actual implementation and evidence in a notebook under ../notebooks/branch_work/, following the notebook convention and D-042/D-045. Use native Markdown cells for the title, contributor table, purpose, scope and data context before concise executable Python Code cells. Execute Code cells in order and retain concise outputs. The default is offline; saved input is read-only, and notebook data stays in memory without notebook-generated dataset files. Each notebook uses a contributor table with registration number, member name and GitHub account; a registration number is permitted only in that table. The [biological data collection branch notebook](../notebooks/branch_work/01_pipeline_biological_data_collection.ipynb) documents the OBIS Area 230 intake and handoff. The [environmental data collection branch notebook](../notebooks/branch_work/02_pipeline_environmental_data_collection.ipynb) documents the Bio-ORACLE catalogue intake, selected rectangle, run evidence and source-validation handoff. The [OBIS cleaning branch notebook](../notebooks/branch_work/03_pipeline_data_cleaning_obis.ipynb) explains the cleaning purpose, concrete column and row rules, branch output counts, preserved quality data and read-only verification. The [Bio-ORACLE cleaning branch notebook](../notebooks/branch_work/04_pipeline_data_cleaning_bio_oracle.ipynb) documents the full array scan, interim NetCDF bundle, output manifest, review item and limits. The [integration branch notebook](../notebooks/branch_work/05_pipeline_data_integration_and_data_cleaning.ipynb) summarizes the integrated outputs, independent environmental verification, current D-054 Policy B results and D-056 paired background profiles; it includes the preserved original dimensions and the new nested JSON representation. Notebook 06 remains the pseudo-absence notebook and the separate EDA is Notebook 07. Branch notebooks are implementation overviews; they do not replace factual contributor logs, scientific records or individual assessed reflections.
