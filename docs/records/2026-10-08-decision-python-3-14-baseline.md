# Decision record

- **ID:** D-039
- **Date:** 2026-10-08
- **Question:** Which Python version should be the OCEAVERA project baseline?
- **Context:** Current OBIS intake and repository-maintenance scripts use the Python standard library and declare compatibility with Python 3.10 or later. The repository CI and initial Conda instructions previously used Python 3.12. The user asked to select the more suitable version for the project and directed the repository to be updated accordingly. The ML framework and scientific package stack have not yet been selected.
- **Options considered:** Keep Python 3.12 as the baseline; adopt Python 3.14 as the baseline; postpone a project baseline until the ML stack is selected.
- **Evidence and source references:** The Python Developer's Guide lists Python 3.14 in bug-fix support through October 2030 and Python 3.12 in security-only support through October 2028 ([version status](https://devguide.python.org/versions/)). Conda documents support for Python 3.14 ([Python environments](https://docs.conda.io/projects/conda/en/stable/user-guide/tasks/manage-python.html)). GitHub's official setup-python action documents version-file configuration and Python 3.14 support ([advanced usage](https://github.com/actions/setup-python/blob/main/docs/advanced-usage.md)). Scientific-library compatibility examples include pandas 2.3.3 for Python 3.14 ([release notes](https://pandas.pydata.org/docs/dev/whatsnew/v2.3.3.html)) and SciPy 1.17's Python 3.11–3.14 support ([release notes](https://docs.scipy.org/doc/scipy/release/1.17.0-notes.html)). These examples do not establish compatibility for every future project dependency.
- **Decision:** Adopt Python 3.14 as the OCEAVERA Python baseline. Record the minor version in the root `.python-version` file, use it for the `OCEAVERA` Conda environment, and configure repository CI to read the same file. Keep the current OBIS scripts' Python 3.10+ compatibility as a code minimum, not the recommended project baseline.
- **Rationale:** Python 3.14 has a longer active bug-fix support window than 3.12, is supported by Conda and the current setup-python action, and current scientific-library releases provide compatibility examples. The present scripts have no dependency or language feature that blocks 3.14. The shared version file reduces drift between local setup instructions and CI.
- **Consequences and limitations:** The CI workflow now reads `.python-version`, and Conda setup instructions use Python 3.14. This selects the Python interpreter baseline only; it does not select an ML framework, scientific packages or full experiment environment. Check the supported Python range and available platform builds for each future dependency before adding it to `requirements.txt`. If the agreed stack cannot support Python 3.14, record evidence and a replacement decision rather than silently changing the baseline. A local helper run on another Python 3.10+ interpreter remains compatible, but no hosted CI run or 3.14 runtime execution is claimed here.
- **Status:** accepted
