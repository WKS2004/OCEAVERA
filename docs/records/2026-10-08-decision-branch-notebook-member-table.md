# Decision D-042 — Branch notebook member table

- **ID:** D-042
- **Date:** 8 October 2026
- **Question:** Which contributor metadata and closing structure should branch work notebooks use?
- **Context:** D-041 established one implementation notebook for each finalised branch. The user subsequently asked to remove reviewed-source-commit detail, permit registration numbers in these branch notebooks as the sole repository exception, use a table that scales to multiple contributors and remove the terminal Handover section.
- **Options considered:** Retain D-041's metadata and ending; omit contributor details; or use one branch-local contributor table and remove source-commit metadata and the terminal Handover section.
- **Evidence and source references:** The existing [branch notebook](../../notebooks/branch_work/pipeline_biological_data_collection.ipynb), [notebook index](../../notebooks/README.md#branch-work-notebook-convention), [member privacy guidance](../../CONTRIBUTING.md#member-privacy) and explicit user direction on 8 October 2026.
- **Decision:** Keep the D-041 branch notebook convention, refined as follows. Top metadata includes project, branch name and review date without a reviewed source commit. Add a contributor table with the exact columns `Registration Number`, `Member Name` and `GitHub Account`, with one row per verified contributor. Registration numbers are permitted only in this table within branch work notebooks; they must not appear in AI-usage logs, other repository files or verification output. Do not include institutional name forms, email addresses or other academic identifiers. End with the notebook's references and next-step context; do not add a separate terminal Handover section.
- **Rationale:** The table accommodates branches with multiple contributors while keeping the requested member metadata in one narrowly defined location. Removing the source commit and terminal Handover content keeps the notebook focused on branch work and its evidence.
- **Consequences and limitations:** The notebook remains a branch-level description and does not establish personal contribution, assessment completion, human acceptance or scientific validity. Use the verified project contributor name and GitHub account; obtain any number from a source the user has authorised and avoid repeating it outside the table. Preserve D-041 as historical context.
- **Status:** accepted
